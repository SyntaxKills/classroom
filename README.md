🎓 CLASSROOM

Plataforma de simulados acadêmicos para estudantes de Análise e Desenvolvimento de Sistemas (ADS).

O CLASSROOM permite criar simulados personalizados por disciplina e semestre, praticar conceitos técnicos e acompanhar o desempenho através de resultados e revisões.

🚀 Acesso

Recurso| Descrição
📝 Simulados| 20 questões de múltipla escolha
📚 Disciplinas| Conteúdos específicos de ADS
🎯 Dificuldade| Básico, intermediário e avançado
📊 Resultados| Acertos, erros, percentual e desempenho
💾 Persistência| Salvamento local via LocalStorage
🔄 Retomada| Continue simulados interrompidos

📖 Disciplinas

- Programação Back-End
- Análise e Projeto de Sistemas Orientada a Objetos
- Desenvolvimento em Banco de Dados
- DevOps
- Gestão de Projetos

🛠️ Tecnologias

Tecnologia| Utilização
HTML5| Estrutura
CSS3| Interface e responsividade
JavaScript ES6+| Lógica e funcionalidades
LocalStorage| Persistência local

📱 Características

- Interface moderna com tema dark e detalhes neon.
- Layout responsivo para dispositivos móveis e desktop.
- Questões interativas com correção e explicações.
- Histórico de simulados e revisão de respostas.
- Sem necessidade de backend ou instalação.

💻 Execução local

Clone o repositório:

git clone https://github.com/SyntaxKills/classroom.git

Entre na pasta:

cd classroom

Abra o arquivo "index.html" no navegador.

🔒 Armazenamento

Os dados do estudante e os simulados são armazenados localmente no navegador através do "LocalStorage". Nenhum servidor ou banco de dados externo é utilizado.
